# ゆきこ歯科 予約データ分析・電話リスト

デンタマップから毎晩自動で保存される予約データを読み、**受付が今日電話すべき患者のリスト**と、院長向けの短い分析を作る。

## 0. 大事な前提

- 数字は必ずファイルを実際に読み込んで計算する（コードを実行する）。推測や概算で数字を作らない。
- これは「予約」のデータ。売上・点数・カルテの情報は入っていない。売上や保険点数について断定しない。
- 患者さんの氏名・電話番号・症状が入っている。結果は保存先フォルダの中にだけ保存し、外部に送らない。
- 院長は歯科医師。歯科の用語はそのまま使ってよいが、経営やデータ分析の専門用語はなるべく避け、使うときは一言説明を添える。
- 「基準日」＝今日。予約日が今日より前の予約を「実績」、今日以降を「今後の予約」とする。

## 1. フォルダとファイル

Googleドライブの「デンタマップ予約データ」フォルダ（毎日 月〜土 17:30 にGoogle Apps Scriptが自動更新）：

| 場所 | 中身 |
|---|---|
| `予約データ_最新.csv` | **分析にはまずこれを使う。** 月次CSVと最新の未来分を、月次CSVの「予約明細表」と同じ22列で1つにまとめたもの（Shift_JIS）。月次CSVがある月は月次（同じ月は最新取得で上書き済み）、それより先は最新の未来分。常に新しいデータが優先されている |
| `予約の埋まり具合_YYYY.csv` | 取得した日ごとに、先の予約日×区分（院長／衛生士／その他）の予約枠数・患者数・キャンセル済み枠数を記録したもの（UTF-8）。列：取得日, 予約日, 曜日, 何日先, 区分, 予約枠数（キャンセル除く）, 患者数, キャンセル済み枠数 |
| `月次\YYYYMMデータ.csv` | 月ごとのCSV（バックアップ画面「過去分」と同じ形式）。先月・今月が毎日上書きされる |
| `未来分\yoyaku_dataYYYYMMDD.csv` | その日時点の未来分CSV（翌日から180日分）。毎日分が残る |
| `最終取得.txt` | 最後に自動取得した日時と「成功／失敗」 |
| `電話リスト\` | このスキルが作るリストの保存先（なければ作る） |

**最初に `最終取得.txt` を確認する。** 今日（日曜なら直前の土曜）の日付で「成功」でなければ、分析はせずに「デンタマップの自動取得が成功していません（内容：○○）」とだけ報告して終わる。

## 2. ファイルの読み方

- `予約データ_最新.csv` は1行目が列名、2行目から予約明細。列（22列）：患者番号, 患者名, 予約日, 予約開始時間, 予約終了時間, 列, 診療内容, 担当１, 担当２, 担当３, 部位番号, カラー番号, 技工, 予約記号, キャンセル, Memo, 来院時間, 案内時間, 完了時間, 来院～案内時間(分), 案内～完了時間(分), Apo link
- 予約日は日付、時間は「09:00」の形にして使う。
- `月次` の個々のファイルを読む必要があるとき（例：月ごとの「当月合計」の確認）は、「（予約明細表）」の次の行（列名）から下が予約明細。その上の「当月合計」の「診療数」は、予約明細の「患者番号がsystem以外で、キャンセルが空欄の行数」と一致するはず。
- 「その日時点でどれだけ予約が入っていたか」の比較（例：先週の同じ曜日の時点と比べて来週の埋まりはどうか、前年同時期との比較）は `予約の埋まり具合_YYYY.csv` を使う。過去の時点の詳しい中身が必要なときだけ `未来分` の該当日のファイルを読む（17列。診療内容のカンマで列が増えた行は、余分な列を診療内容に戻して「、」でつなぐ）。
- 最初に、読み込んだ期間と件数を1行で確認する（「○年○月〜○年○月、○件」）。

## 3. 各列の意味

- **患者番号**：数字＝登録済み患者。「system」＝患者ではなく枠の押さえ（休み・KEEP・昼休み・セミナー・キャンセル待ち枠など）。空欄＝ネット予約で入ったまま患者登録されていない人。
- **患者名**：全角スペースの有無やカナ書きでばらつく。
- **予約日**：8桁（例 20261112）。**予約開始時間・予約終了時間**：4桁（例 0900）。基本は45分枠。
- **列（ユニット）**：「院長1」「院長2」＝院長の診療枠、「大山果奈」「DH」＝歯科衛生士の枠、「急患」、「その他」。「7」「列8」は予備。
- **診療内容**：受付が自由入力した予定の処置。表記ゆれあり（例：SPT３M／SPT3M／SPT３、sp／SP）。全角→半角、大文字化してそろえる。複数の処置は「、」区切り。空欄もある。
- **キャンセル**：空欄＝有効な予約。「無断キャンセル」「TELキャンセル」（電話で取り消し）「TELキャンセル(変更)」（電話で別の日に変更）。「NETキャンセル」「NETキャンセル(変更)」もありうる。
- **Memo**：受付メモ。「【自動登録】」で始まるもの＝ネット予約（症状・電話番号「tel:」・メールを含む）。「[キャンセル 2026/11/10(火)…]」を含むもの＝その日時から移してきた予約。
- **予約記号**（▲●◆など）：意味は未確認。推測しない。
- 担当１〜３・部位番号・来院時間〜Apo link：ほとんど空欄なので使わなくてよい。

### カラー番号（予約の色）の意味
カラー番号は10進数。16進数にすると色コードになる。

| 16711680 | FF0000 赤 | 急患 |
| 16760576 | FFBF00 山吹色 | ネット予約、再初診 |
| 16776960 | FFFF00 黄色 | 初診 |

- 赤紫（自費）は自費の予約件数の目安として使ってよいが、金額は分からない。

## 4. 診療内容の分類

- **メンテナンス系**：SPT○M（○は次回までの月数。例 SPT3M＝3か月ごと）、SC、SP、P重防・3P重防・4P重防、リコール、検査１〜３、シーラント、SRP
- **保存・根管**：CR、C処、RCT、RCF、麻抜、感処
- **補綴**：コア imp／コア set、In imp／In set、CAD imp／CAD set、FCK、前装冠、Br、TEK（imp＝印象、set＝装着）
- **義歯**：PD imp／PD set、BT、TF（試適）、義歯調整、義歯修理
- **外科**：EXT、智歯EXT、抜糸
- **インプラント**：一次OPE（GBRを伴うこともある）、二次OPE、ステント印象／ステントセット、CT説明、インプラント説明・診断・調整・set、「インプラント」を含む補綴
- **新患**：初診、再初診
- **その他**：急患、笑気希望、プレオルソ、マウスピース、ホワイトニング、訪問診療。分類できないものもここに入れる

表記をそろえたり、診療内容から分類を推定したりして作った集計・リストには、必ずその箇所に「※診療内容の表記を推定でまとめています」と書く。

## 5. 集計のルール

- **有効予約**＝患者番号がsystemでなく、キャンセルが空欄の行
- **来院**＝実績（今日より前）の有効予約。来院記録はないので、これを来院とみなす
- **キャンセル率**＝キャンセル件数 ÷（来院＋キャンセル件数）
- 同じ患者が同じ日に複数枠を取ることがある。「来院患者数」は「患者＋予約日」の重複を除いて数え、「枠数」と区別する
- **患者の見分け方**：患者番号で見分ける。患者番号が空欄の行は、氏名のスペースを除いて、同じ氏名の登録済み患者が1人だけいればその人とみなす（「※氏名で照合」と印を付ける）。見つからない、または2人以上いる場合は氏名ごとに「仮番号」を振って別の患者として扱う（「※仮番号」と印を付ける）
- データがある最初の月（2024年11月）より前の通院歴は分からない

## 6. 毎日作るもの

### (1) 電話リスト（最優先）

**リストA：予約を取ってもらうために電話する患者**
今後の有効予約がなく、次のどれかに当てはまる人。

- (a) **治療の途中**：最後の来院が治療の途中（RCT、コア imp、In imp、CAD imp、FCK imp、PD imp、Br imp、BT、TF、TEK、麻抜、試適、一次OPE、二次OPEなど）で、2週間以上経っている
- (b) **キャンセルしたまま**：直近の予約が無断キャンセルかTELキャンセルで、その後の予約が入っていない
- (c) **新患のまま止まっている**：初診・再初診・ネット予約の初回のあと、来院が1回だけで次の予約がない
- (d) **メンテナンスの時期を過ぎた**：最後の来院がメンテナンス系で、最後の来院日から「通院間隔＋2週間」以上経っている（通院間隔は最後のSPT○Mの○か月。分からなければ3か月）

優先順位は (a)→(b)→(c)→(d)。同じ種類の中では、経過が短い人（連絡すれば戻りやすい人）から。最後の来院から1年以上経っている人は別シートに分ける。

**リストB：予約日の前に確認の電話をする患者**
今日から2週間以内に有効予約がある人のうち、次のどれかに当てはまる人。予約日の早い順。

- 過去に無断キャンセルが1回以上ある
- 過去のキャンセル率が30%以上（予約3回以上の人）
- 初めて来る人（初診、またはネット予約で患者番号が空欄）

**リストの列**：優先順位、理由（具体的に）、患者番号、患者名、電話番号（Memoに「tel:」があれば。なければ空欄）、担当衛生士、最後の来院日、最後の診療内容、次の予約日と内容（リストB）、これまでの来院回数、キャンセル回数（種類別）、直近のMemo、そのあとに空欄の「電話した日」「結果」「次の予約日」。

**前回までの電話の結果を引き継ぐ**：`電話リスト\` に過去のファイルがあれば読み、「結果」が書かれている患者は、その日から14日間はリストAから外す（「留守電」「不在」など、つながらなかった結果は外さない）。

**保存**：`電話リスト\電話リスト_YYYYMMDD.xlsx`。シートは「A_予約を取る電話」「A_1年以上」「B_確認の電話」「前提としたこと」。見出しを固定し、列幅を整える。

### (2) 院長への報告（チャットに書く）

10行程度で、次の順に書く。

1. 電話リストの件数（A：○件、B：○件）と、いちばん優先度の高い3人（患者名・理由）
2. 明日の予約で気をつけること（無断キャンセル歴のある人、初めて来る人）
3. 今週と来週の予約の埋まり具合（衛生士枠・院長枠それぞれ。`予約の埋まり具合` で、1週間前の時点と比べて増えたか、前年同時期と比べて多いか少ないか）
4. 気づいた点があれば1〜2行（例：キャンセルが続いている、新患が減っている など）

事実（データから分かること）と、推測・提案は分けて書く。

### (3) 月に1回（毎月1日の実行時だけ）の分析

前月までのデータで次をまとめ、`電話リスト\月次分析_YYYYMM.xlsx` に保存し、報告に要点を加える。

1. 月ごとの来院患者数・枠数・キャンセル率（内訳つき）・新患数（初診＋再初診＋ネット予約の初回）。前年同月との比較
2. 院長枠（院長1・2）と衛生士枠（大山果奈・DH）の月別の枠数と、診療内容の内訳
3. 曜日×時間帯の平均予約数とキャンセル率（混む時間・空きやすい時間）
4. 担当衛生士ごとのメンテナンス患者数と、メンテナンス離脱の人数
5. 新患の定着（初診のあと2回目以降に来た割合、メンテナンスに移った割合）
6. すぐ取り組めることを3つ。それぞれ根拠の数字と具体的な動き方を添える

## 7. 最後に

- 判断に迷った定義や表記ゆれのまとめ方は、Excelの「前提としたこと」シートに箇条書きで残す。
- エラーで途中までしかできなかったときは、どこまでできて何が残ったかを報告する。
